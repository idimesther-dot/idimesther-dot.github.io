# Esther Idim — GitHub Pages Portfolio

A responsive static portfolio website for Esther Idim Nehemiah.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository**.
2. For the main personal website, name the repository exactly:
   `YOUR-GITHUB-USERNAME.github.io`
3. Extract this ZIP file on your computer.
4. Upload the contents of the `esther-idim-portfolio` folder to the **root** of that repository. The `index.html` file must be at the repository root, not inside another nested folder.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select **main** and **/(root)**, then Save.
8. Wait a few minutes. Your site should appear at:
   `https://YOUR-GITHUB-USERNAME.github.io`

## Before publishing

- Replace the placeholder `YOUR-GITHUB-USERNAME` in any social/profile links you choose to add.
- Check your phone number and email address.
- Open every portfolio link and confirm it is public and points to the intended work.
- The site currently uses the CV PDF supplied for this project at `assets/Esther-Idim-CV.pdf`.
- The supplied Canva site could not be loaded in the website-building environment. This version follows the style stated in its URL: dark brown, white and yellow, with a classic minimal layout. If you export the Canva design as a PDF or image and upload it, the styling can be matched more closely.
